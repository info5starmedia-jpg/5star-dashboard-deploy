# How to Use the 5Star Dashboard

## Start the app
1. Run: `npm run dev`
2. Open: http://localhost:3000

## Sign in
- Visit `/signin` and use Discord or Google.

## Customer dashboard (`/dashboard`)
- View subscription status and renewal date.
- Review your last five invoices.
- Use `/billing` to manage your subscription.

## Knowledge Base (`/kb`)
- Browse placeholder sections (content can be added later).

## Admin tools (admin-only)
- `/admin` for shortcuts to inventory, invoices, analytics, and audit.
- `/admin/inventory` to add stock and see valuation metrics.
- `/admin/invoices` to create invoices and download PDFs.
- `/admin/analytics` for revenue and low stock summaries.
- `/admin/audit` to manage users (roles + enable/disable) and view audit logs.
